# Rosie Health Hub

A private daily health log for Rosie (Cavapoochon, born 31 January 2021). One entry per day records her health score, stool, symptoms, medications, walks, food, treats and location, and the app turns that into history, insights, medication stock tracking and achievements.

It is an installable web app (PWA), originally generated with [Lovable](https://lovable.dev), now deployed to Cloudflare Workers, with data in a Supabase (Postgres) database.

## Where things live

- **Code:** this repository (`TylerRhysRoberts/Rosie`). Lovable also commits here, as `gpt-engineer-app[bot]`.
- **Hosting:** Cloudflare Worker `rosie`, built from this repo.
- **Database and auth:** Supabase project `uzdwydyaqqkyrgpxutgf`, provisioned and owned by **Lovable Cloud**. It is not in your own Supabase account.
- **Google sign-in:** brokered by Lovable (`@lovable.dev/cloud-auth-js`).

Full detail: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). What to fix and build next: [docs/ROADMAP.md](docs/ROADMAP.md).

## Running locally

Requires [Bun](https://bun.sh) (the lockfile is `bun.lockb`) and Node 22.

```sh
bun install
bun run dev        # http://localhost:8080
bun run build      # production build for Cloudflare (dist/)
bun run lint
```

`.env` is committed and holds only the Supabase URL and publishable (anon) key, which are public by design. The service role key used by guest mode is not in the repo and must be set as a secret on the Worker (`SUPABASE_SERVICE_ROLE_KEY`).

## Project layout

```
src/
  routes/          one file per screen (TanStack Router, file-based)
  components/      app components; components/ui/ is the shadcn/ui kit
  lib/             data access and domain logic (logs, inventory, achievements, milestones)
  hooks/           useAuth, useTheme, useIsMobile
  integrations/    Supabase clients and Lovable auth (auto-generated by Lovable)
  styles.css       Tailwind v4 theme tokens (light and dark)
supabase/
  migrations/      schema history, applied by Lovable
public/            PWA manifest, service worker, icons
docs/              architecture and roadmap
```
